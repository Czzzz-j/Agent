# 家具智能客服项目面试资料目录

这个目录用于集中存放“项目理解与面试手册”相关资料，避免 Word 产物散落在项目根目录。

## 目录说明

- `archive/`
  - 存放历史生成过的 DOCX 版本。
  - 这些是旧快照，不是当前桌面上的最终版。

- `extracted/`
  - 存放从 DOCX 抽取出来的文本或检查中间产物。
  - 主要用于回溯内容，不建议作为正式阅读入口。

## 维护原则

1. 项目源码、配置、数据集、测试文件不要放到这里。
2. 新生成的面试手册快照可以放到 `archive/`。
3. 中间抽取文本、渲染检查日志等可以放到 `extracted/` 或项目根目录的 `tmp/`。
4. 如果后续要重做文档，优先改 `Agent/scripts/build_beginner_project_handbook.py`，再重新生成 DOCX。
